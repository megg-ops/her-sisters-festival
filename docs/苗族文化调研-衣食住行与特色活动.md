## 一、衣｜苗族服饰（国家级非遗）

**基本分类**：苗语称「呕欠」，分**童装、便装、盛装**。盛装为节日婚嫁之服，繁复华丽（苗语「呕欠嘎给希」）；便装素净简洁供日常。盛装配套「**呕欠涛**」（银衣）+ **百褶裙** + 前后围腰。（[中国民族文化资源库](http://www.minwang.com.cn/eportal/ui?pageId=663068&articleKey=675625&columnId=682291)、[百度百科·苗族服饰](https://baike.baidu.com/item/%E8%8B%97%E6%97%8F%E6%9C%8D%E9%A5%B0/1325332)）

**黔东南样式**：雷公山式（凯里/丹寨/雷山/台江一带）盛装为**大领对襟衣**，便装为圆领大襟衣，配围腰、绑腿、花鞋、银饰头饰。苗族服饰图案能**表意、识别族类与支系**，被称为「**穿在身上的史诗**」。

**百鸟衣**：榕江摆贝支系「百鸟衣羽毛裙」以百鸟造型为主体、龙凤穿插，体现鸟图腾崇拜，由苗绣绣成，是苗族服饰最具代表性的形制。（[中国非物质文化遗产网](https://www.ihchina.cn/project_details/15045/)）

**银饰**：盛装银饰包括**泡项圈**（叠戴三件以上，造型源自水泡幻化的美神「仰阿莎」传说）、银冠（牛角形）、银衣片、手镯等。姑娘只在节日踩鼓场和婚礼时全身穿戴。（[国立故宫博物院特展](https://theme.npm.edu.tw/exh104/guizhou/ch/ch01.html)、[中国丝绸博物馆](https://www.chinasilkmuseum.com/yz/info_18.aspx?itemid=26654)）

**🎮 游戏化映射**：衣柜 = 便装/盛装双状态切换（白天便装劳作，节日盛装赴会）；银饰与「穿在身上的史诗」是图鉴文案的富矿。百鸟衣可做隐藏款。

## 二、食｜苗族饮食

总特征：**以酸为主、以糯为常、以鱼为鲜、以酒为礼**——源于山区缺盐的「以酸代盐」史。（[国家民委·苗族风俗文化](https://www.neac.gov.cn/seac/ztzl/mz/fswh.shtml)）

| 食物 | 要点 | 游戏化价值 |
|---|---|---|
| **酸汤鱼** | 白酸（淘米水/米汤瓦罐发酵）与红酸（毛辣角/野生西红柿），家家自制 | 厨房交互首选：发酵等待机制 |
| **腌鱼** | 黔东南苗侗代表美食，田鱼腌制，存于**酸坛** | 厨房道具 |
| **糯米饭** | 主食，木甑一次蒸够一天，旧时手捏团食 | 晨起甑子饭交互 |
| **姊妹饭** | 五色糯米饭，植物染汁浸泡蒸熟（黑/红/黄/紫/白）；姊妹节核心食品，青年男女借饭传情，「藏在饭里的浪漫」 | **厨房主交互**：选植物染色，与蜡染共用的「山里取色」知识 |
| **油茶** | 苗族饮食「三宝」之一（油茶、甜酒、蜜饯茶）；油盐姜茶同炒煮制；传统问候语「吃过茶否？」 | 早饭对话素材 |
| **米酒/甜酒** | 「三日不呷酸，走路打趔趄」；待客礼节 | 拦门酒彩蛋 |

（[苗族食俗·百度百科](https://baike.baidu.com/item/%E8%8B%97%E6%97%8F%E9%A3%9F%E4%BF%97/10837490)、[姊妹饭资料见姊妹节条目](https://baike.baidu.com/item/%E5%A7%90%E5%A6%B9%E8%8A%82/6198140)）

**🎮 游戏化映射**：厨房做**姊妹饭**（选枫叶/黄饭花/红蓝草 → 蒸出五色饭）是最优交互——材料来自山野，与采蓝靛/蜡染形成同一知识体系的呼应；酸汤鱼可做次日彩蛋。

## 三、住｜吊脚楼与室内陈设

**分层**：依山而建，两层或三层——**底层**圈牲畜堆柴草；**中层**为生活核心（堂屋、卧室、厨房）；**顶层**矮，做粮仓。板壁刨光杉木封装，窗棂木条拼花。（[百度百科·苗族吊脚楼](https://baike.baidu.com/item/%E8%8B%97%E6%97%8F%E5%90%8A%E8%84%9A%E6%A5%BC/1281564)、[中国非物质文化遗产网·吊脚楼](https://www.ihchina.cn/news_1_details/11417.html)）

**堂屋**：家庭最神圣空间——迎客、宴宾、祭祖。正中设**神龛**（供列祖列宗），讲究「神龛高过堂屋门，子孙发在自家门」。⚠️ **游戏化注意：神龛不作为可交互对象**，尊重其神圣性。

**火塘**：生活中心——青石板砌方形坑、椿木围边、周围铺「地楼」木地板；集做饭/取暖/待客于一体；上挂**炕架**熏腊肉；**铁三脚架**受崇拜。**禁忌**（可做阿婆的教导对话，不做惩罚机制）：不能踩柴蔸（意为踩老人）、不能跨越火塘、不能向火塘泼水。（[中国民族文化资源库·苗族火塘文化](http://www.minwang.com.cn/mzwhzyk/674771/682366/682371/805520/index.html)）

**美人靠**：堂前檐下 S 形曲栏靠椅，苗族姑娘在此**挑花刺绣**——天然的「女主角专属座位」。

**家具**：矮脚几案（保留「坐皆蹲居」古俗）、原始木凳，整体古朴简约。

**🎮 游戏化映射**：室内场景元素清单 = 火塘（可点：生火/烧水/烤粑）+ 炕架 + 三脚架 + 甑子 + 酸坛 + 织机 + 纺车 + 美人靠（点开是阿婆的绣活）+ 墙上旧蓝布。禁忌做成「阿婆轻声提醒」，传递文化而不说教。

## 四、行｜日常与社交

- **赶场**（赶集/「赶山」）：定期集市，既是贸易也是社会活动与**游方**时机；如今苗族服饰在集市「占了一条街」。→ 可做室外场景之一或背景叙事。（[凤凰新闻网](https://www.fhxww.cn/content/2013/09/24/478541.html)、[中国日报网](https://cn.chinadaily.com.cn/a/202211/29/WS6385d106a3102ada8b22476c.html)）
- **游方**：青年男女传统社交恋爱方式，多在农闲、节日、赶场天的「游方坡/游方场」对歌交往。⚠️ 主角是小女孩，**不宜做主交互**，可作为「大姐姐们去游方坡了」的背景交代。（[百度百科·苗族节日](https://baike.baidu.com/item/%E8%8B%97%E6%97%8F%E8%8A%82%E6%97%A5/5372022)）
- **待客礼**：客人来访杀鸡宰鸭、远客先饮**牛角酒**；鸡头敬长者、鸡腿赐幼者——「鸡腿给年纪最小的人」正好给主角。（[保靖新闻网](https://www.baojingrm.cn/content/2012/02/23/5894041.html)）
- **拦门酒**：进寨设卡敬酒，西江千户苗寨十二道拦门酒各寓意一种祝福（恭喜/善良/勤劳/勇敢…）；牛角杯只能用嘴接不能用手接。→ 待客彩蛋交互。（[百度百科·牛角酒](https://baike.baidu.com/item/%E7%89%9B%E8%A7%92%E9%85%92/10325395)）
- **劳动分工**：织布和蜡染由女子专责——女主角学艺的文化依据。（[黎苗文化网](https://wzs.hainan.gov.cn/wzs/lmwh/200805/831bd584ee164e4498d1a6012c0e84a4.shtml)）

## 六、特色物品清单（室内可点交互道具库）

**纺织类**：纺车（纺麻纱）、台式织机（织衣裙麻布）、腰机（织花带/挎包）——苗族「麻文化」十五道工序之一环。（[腰机织布技艺·暨大文创院](https://ccjd.jnu.edu.cn/2022/0414/c23053a690409/page.htm)）

**饮食类**：甑子（木蒸具，先煮半熟沥干再蒸，「甑子饭」带木香）、酸坛（家家有的腌制坛）、火塘三脚架、炕架（熏腊肉）。

**礼仪娱乐类**：牛角杯（只能嘴接不能手接）、芦笙（六管竹制，大者丈余小者八九寸）、木鼓（祭祀/木鼓舞）。

**其他**：背篓（山地背负工具）、美人靠、银饰全套（冠/项圈/银衣）、蜡刀、蓝靛染缸。

## 七、48h 范围建议（供讨论）

**室内（主场）**：火塘晨景 + 衣柜换装（便装/盛装两套）+ 厨房姊妹饭（植物染交互）+ 织机蜡案（沿用 v2 蜡染原型）
**室外（一场为限）**：姊妹节踩鼓场（穿盛装、带姊妹饭赴会）——把室内三个产出（盛装、五色饭、蜡染布）全部带进室外场景「使用」一次，完成「一天」的闭环
**彩蛋**：拦门酒/牛角杯、美人靠绣活、大姐姐去游方坡
**明确回避**：神龛交互、游方主玩法、鼓藏节祭祀
