## 一、背景故事

### 1.1 地点与时间

贵州黔东南，清水江边的施洞镇。每年农历三月（具体节期以当地实际为准 `[待核验]`），这里会过姊妹节：家家泡米蒸姊妹饭，姑娘们穿上盛装，河畔场地热闹起来，年轻人对歌、赠饭。节日不是表演，是镇上一年里真实会到来的一天。

### 1.2 人物（实现版）

demo 中**唯一开口的角色是外婆**；妈妈、阿月、阿禾均为立绘/氛围角色，不发台词。人物设定保留，但台词范围按实现收敛。

| 角色 | 设定 | 在 demo 中的呈现 |
|---|---|---|
| 阿岚（女主） | 约 18 岁，在施洞长大。话不多，手勤，心里有主意但还没说出口。往年跟着长辈"照做"，今年第一次一个人把节日准备完 | 第一人称旁白/内心独白的主体（对话带说话人固定标「阿岚」）；室内便装立绘 → 室外盛装立绘 |
| 外婆 | 安静，坐在火塘边。只说自己有把握的事，不确定的直说"这个我讲不准" | **唯一问答承载者**：5 个文化物件的作答者；换装完成时给一句总结；头顶气泡对白 |
| 妈妈 | 利落，讲究规矩 | 立绘占位，**无台词**（v0.1 的叫起、厨房、早退、换装规则台词已删） |
| 阿月 | 同村姊妹，节日场地引路人 | 室外立绘占位（招手），**无台词** |
| 阿禾 | 歌场上的年轻同伴。性别与关系表达克制，不进入任何攻略系统 | 室外立绘占位（侧背影，匿名背景人物）；作为赠饭对象出现，**无台词**（对方回应仅以阿岚旁白一笔带过） |

> 名字说明：v0.1 用占位符 `{名字}` / 家称"幺妹"，demo 已定名「阿岚」并写入代码；本版据此定名。正式发布前，苗语名及准确发音仍须由当地文化顾问确认（PRD §5.1）。

### 1.3 故事前提

去年，阿岚是跟在后面提篮子的人。今年，轮到她自己来：泡米、染米、蒸饭、装篮；哪一件盛装配哪一场合；出门前该问外婆的那一件事。外婆坐在火塘边，不帮忙，也不催，像是专门在等她开口问。

从清晨的木楼到河畔的姊妹节，玩家陪她把这"一天"从头走到尾：做完一顿姊妹饭，穿好一身盛装，问出一个一直没问的问题，最后亲手把篮子递出去——并且第一次知道，自己为什么要递。

### 1.4 三条叙事线

1. **动作线（玩家做）**：做饭 → 换装 → 问外婆 → 离家 → 听歌 → 赠饭。（室内三件事无固定顺序）
2. **问题线（玩家问）**："为什么今天还要过这个节？"不给标准答案，经由外婆的对白、物件的来历和结尾收束句，让玩家自己拼出半个答案。
3. **细节线（系统记）**：姊妹饭主色与心情色、问过的物件、听歌心意、赠饭心意 → 全部汇入结尾记忆卡。

### 1.5 文本基调纪律

- 对白短：单句 ≤25 字为主，单条气泡 ≤4 行（PRD §11.3）。
- 旁白承担内心戏，对白不解释系统。
- 不出现：好感度、攻略、配对暗示、"美女/仙女"式凝视、景区解说词腔调。
- 当代物件自然存在，不制造"传统+手机"的反差噱头（PRODUCT.md 原则 4）。
- 所有文化陈述只能来自审核知识库；涉及处均已标注 `[待核验]`/`[原型]`。
- 外婆之外的家人保持克制：能用旁白与画面表达的，不硬加 NPC 台词。

## 二、分场景剧情文本（对齐 demo）

demo 的实际场景结构：**intro 浮层 → 室内「家屋」（第一幕）→ 室外「江畔」（第二幕）→ ending 记忆卡浮层**。没有独立的卧房场景与寨道过场；离家＝室内切室外的场景切换。

状态变量（demo `initialState()`）：`indoor.{meal,outfit,culture}` / `outdoor.{song,gift}` / `mealColors[]` / `mealColor` / `moodColor` / `moodLine` / `outfit` / `outfitLayers[]` / `question` / `intent`（听歌心意）/ `giftIntent` / `giftIntentNote`。

### S0 封面（intro 浮层）

**画面**：封面背景图（`assets/scene/封面背景-v1.webp`），标题区留白。
**文案（demo 实装）**：
- 眉标：一段发生在当代施洞的互动故事
- 标题：她的姊妹节
- 副题：陪阿岚准备姊妹饭、穿好节日盛装，再沿清水江走进她第一次独自参加的姊妹节。
- 主按钮：【从清晨开始】
- 辅助功能入口：操作说明 / 设置（字幕 · 减少动态 · 环境声音）在顶栏常驻

### S1 家屋 · 室内枢纽（第一幕）

**顶栏信息**：第一幕 · 家屋 ／ 出门前的清晨 ／ 姊妹节当天 · 08:10
**入场旁白（阿岚）**：饭要蒸好，衣裳也要穿稳。今天，是我第一次自己准备好再去江边。

**主热点（3 个）**：
| 热点 | 动作 | 状态 |
|---|---|---|
| 挑选盛装 | 打开换装抽屉（S3） | 可行动 |
| 制作姊妹饭 | 打开做饭抽屉（S2） | 可行动 |
| 还不能出门 | 三件必做未齐时禁用；齐后启用为离家 | 未完成时点击 toast「先完成出门前的三件事」 |

**文化物件标记（5 个，独立可点，外婆作答，不计入主热点上限）**：银簪 · 绣片 · 姊妹饭竹篮 · 火塘 · 酸汤坛。问答内容见 §三。

**必做任务面板**：
- ○ 蒸好一篮姊妹饭
- ○ 穿好节日盛装
- ○ 向外婆问一件事

三项全部完成后，「还不能出门」热点解除禁用，可离家进入江畔。

### S2 做饭抽屉：姊妹饭四步

> 色彩三重表达（色名 + 纹样标签/色块 + 文字，PRD §16）。染材与色名为原型草案 `[原型]`，进入正式内容前须由施洞当地文化顾问核验（此为文档标注，界面不再显示占位/待核验字样）。

**第一步 · 选色**（`state.mealColors`）
- 引导文案：外婆在盆边留了五样色样布条：红染姊妹花，紫染紫草，黄染密蒙花，黑染枫香树叶，白色留本色。五样都要选上。
- 交互：红（姊妹花）/ 紫（紫草）/ 黄（密蒙花，即黄饭花）/ 黑（枫香树叶）/ 白（本色糯米），五色**全选**才可继续（demo 无"选错"判定，与 v0.1 的对错逻辑不同）。染材口径依姊妹饭常见真实工艺 `[原型]`，正式内容前须核验。
- 未选满：toast「五样都要选上」。

**第二步 · 蒸制**（`mealCookSteps`）
- 引导文案：把煮色素、浸泡上色与分甑蒸制按顺序完成。漏了步骤会给你轻提示。
- 交互顺序：① 煮色素 → ② 浸泡上色 → ③ 分甑蒸制，必须按序。
- 顺序错：toast「先完成「煮色素/浸泡上色/分甑蒸制」」（提示当前应做的下一步，保留已完成步骤）。
- 三步齐：toast「蒸汽起来了，火候刚好」，蒸汽局部动效。
- 工序与植物染材为原型草案 `[原型]`，须经施洞当地文化顾问核验（文档标注，界面不再显示"交互占位/待核验"字样）。

**第三步 · 装篮**（`mealFrame`）
- 引导文案：把蒸好的彩色糯米装进竹篮，再用绣帕包好。
- 交互：把饭装进竹篮 → 用绣帕包好（两步顺序）。
- 提示：toast「彩色的糯米装进了竹篮」/「绣帕包好了」。

**第四步 · 心情色**（`state.moodColor` / `moodLine`）
- 引导文案：篮子的颜色定了。那今天的心情，是哪种颜色？
- 三选一（选后即时显示对应句）：
  - 【沉静的河青】→ 像江面没起风的时候。就它了。
  - 【热烈的茜红】→ 像火塘里最亮的那一下。就它了。
  - 【暖和的日赭】→ 像早上照进窗的那束光。就它了。
- 完成（按钮「带上心情出发」）→ `indoor.meal=true`，任务打勾。
- 收束旁白：红、紫、黄、黑、白，五色姊妹饭装好了。心情是{去掉前缀的心情色}。等到了江边，再把这份心意送出去。

### S3 换装抽屉：施洞盛装五层

> 五层顺序按 PRD §8.3，部件称谓据《她的姊妹节-盛装部件称谓调研.md》。demo 每层为**单选**（非 v0.1 的每层 2–3 选项）；预览用同一画布的六张完整状态图切换，避免人体/服饰错位。形制据馆藏公开资料转绘，为原型草案 `[原型]`，须经当地核验（文档标注，界面不再显示"原型资料/待当地复核"字样）。

| 层 | 部件 | 场合说明（草案，穿戴时显示） |
|---|---|---|
| 1 | 大领对襟衣 | 先把衣穿正。姊妹节这一身，跟赶场穿的不一样。 `[待核验]` |
| 2 | 百褶裙 | 百褶裙要及踝。走起路来，裙摆才是稳的。 `[待核验]` |
| 3 | 围腰 | 围腰系好，绣片莫歪。这是手上绣出来的东西。 `[待核验]` |
| 4 | 银项圈 | 银饰压得住这身衣裳。戴多戴少，看家里备的。 `[待核验]` |
| 5 | 银角银冠 | 这才是姊妹节戴的。重是重，戴稳就好。 `[待核验]` 银饰头冠生成风险高，重点复核 |

- 每层按钮：「穿上{部件}」；可「上一步」回退（回退会移除该层）。
- 五层齐 → 确认页旁白：镜子里这个人，一年里头也见不了几回。……是我。
- 点「确认穿好」→ `indoor.outfit=true`；`state.outfit="施洞盛装 · 银角银冠全套"`。
- 外婆（气泡）：衣裳不是穿得越满越好。站稳、走稳，知道自己为什么穿，才算准备好。
  - 气泡收起兜底旁白：外婆看了看我身上的盛装，点了点头。
- 盛装立绘状态延续至室外场景。

### S4 文化问答：外婆 × 5 物件

见 §三。点任一物件标记 → 外婆头顶弹出 2–3 个建议问题 → 作答（AI 优先 / 离线预设兜底）→ 气泡底部「查看来源」织带。完成至少一次即 `indoor.culture=true`。

### S5 离家（场景切换）

三件必做齐后，点「还不能出门」（此时已启用）→ 直接切换到室外江畔（无独立门口/寨道场景）。
- 入场旁白（阿岚）：江边比我想的更热闹。先不急着把饭送出去，我想听一听大家怎么唱。
- 顶栏更新：第二幕 · 江畔 ／ 走进姊妹节 ／ 清水江畔 · 11:40
- 室外必做任务面板：○ 听完一段迎客歌意 ／ ○ 赠出准备好的姊妹饭

### S6 对歌抽屉：听见，再回应（三步）

> demo 实装为**纯前端静态文案**：无 AI 生成、无意象池、无玩家自填短句（v0.1 的这三项均未落地，降级为赛后 P2）。歌声为 30 秒演示混音，只承担场景氛围。

**第一步 · 聆听**
- 引导文案：先听这段 30 秒演示混音，感受江畔对歌的氛围。
- 交互：【聆听 30 秒歌声】（可暂停/继续/重听；音频失败可继续用字幕）。字幕：♪ 风从江面来，人群的歌声在木楼之间接续。（Riverside Sisters Bloom · 30 秒演示混音）

**第二步 · 选择回声意象**（`state.intent`，三选一）
- 引导文案：现在选择一句「回声意象」，它代表阿岚此刻想表达的心情。
- 选项：把祝福送给朋友 ／ 把勇气留给自己 ／ 谢谢家人的陪伴

**第三步 · 回应**
- 字幕：江水记住来路，饭香记住清晨。阿岚想：{所选意象}。
- 完成 → `outdoor.song=true`。
- 收束旁白：我不用唱得和谁一样。先听见别人，再把自己的话稳稳送出去。

### S7 赠饭抽屉：赠出姊妹饭（四心意）

> demo 增强版（v0.2）：由原「单键递出」扩为**四心意选择**（承载阿岚递出时想说的一句话）。纯前端，无对错、无好感度、无拒绝分支。demo 未区分赠饭对象立绘，**不做对方开口的回应气泡**，对方回应仅以阿岚旁白一笔带过。

**引导文案**：把清晨准备好的那一篮饭送出去。先选一句今天想说的话——这里不设置「正确对象」或好感度，重点是完成一次带着个人心意的赠予。

**心意选择**（`state.giftIntent`，四选一；每项显示递出时要说的话）：
| 心意 | 递出时说 |
|---|---|
| 感谢 | 谢谢你今年也来。 |
| 思念 | 好久没见你咯。 |
| 期待 | 明年姊妹节，还来。 |
| 祝福 | 愿你今年顺顺当当。 |

- 未选：toast「先选一句今天想说的话」。
- 点「把饭递出去」→ `outdoor.gift=true`，`giftIntentNote` 记录该句。
- 递出旁白（阿岚）：我把篮子递过去，轻声说：「{递出的话}」对方双手接过，笑了笑。
- 收束旁白（阿岚）：原来准备好的意义，不是证明我会多少，而是我终于能把一份心意交到别人手里。
- → 进入结尾记忆卡。

### S8 结尾：记忆卡（ending 浮层）

**固定文案**：
- 眉标：今日记忆 · 清水江畔
- 标题：她自己准备好的一天
- 收束句：文化不是摆在橱窗里的符号。它在一道饭、一套衣裳、一次提问和一次赠予里继续发生。

**记忆卡条目（自动填充当天选择）**：
| 条目 | 内容来源 |
|---|---|
| 姊妹饭 | `mealColor` + `moodColor`（如「五色姊妹饭 · 沉静 · 河青」） |
| 节日衣装 | `outfit`（施洞盛装 · 银角银冠全套） |
| 问过外婆 | `question`（如「银簪：这支银簪是哪样时候戴的？」） |
| 心里的回声 | `intent`（听歌所选意象） |
| 递饭时说 | `giftIntent` + `giftIntentNote`（如「感谢 · 「谢谢你今年也来。」」） |

**出口**：【再走一次】（清空本轮剧情状态，保留偏好）／【留在江边】（关闭记忆卡浮层）。

## 三、外婆的文化问答（物件 × 预设回答）

> 交互模式见 PRD §8.4：建议问题 2–3 个；回答一句；底部「查看来源」织带（抽屉文案：「外婆的回答只来自下面这些资料。」+ 来源链接）。
> **以下与 `src/data/knowledge.json` 及 demo `CULTURE_OBJECTS` 逐字一致**，全部为 `[原型]` 草案，依据 PRD §9.4 公开资料撰写（此为文档标注；界面不再显示"原型资料/待当地复核"字样）。
> AI 路径（ADR-004）：优先走 `/api/ask`（6s 超时），任何失败/`file://` 打开自动回落本表预设（界面不再显示"离线资料"标签，玩家无感切换）。

### 3.1 银簪（堂屋 · 外婆身边簪盒）

| 建议问题 | 预设回答 |
|---|---|
| 这支银簪是哪样时候戴的？ | 这是盛装时候的簪子。大日子才戴，平时收在盒盒头。 |
| 是你年轻时候的吗？ | 我戴了几十年咯。是哪样来的，你以后去问你妈妈。 |
| 为哪样节日要戴银饰？ | 银饰是盛装的一部分。姊妹节这样的大日子，衣裳要齐整，头上也要齐整。 |

来源：贵州省博物馆《馆藏台江施洞苗族女盛装银饰》；中国非物质文化遗产网。
边界：簪子来历不展开（答"去问你妈妈"）；银饰纹样与尺寸细节不作普化表述。

### 3.2 绣片（堂屋 · 绣篮）

| 建议问题 | 预设回答 |
|---|---|
| 这块绣片是哪样绣的？ | 一针一针绣的。学绣花没有捷径，先是学拆，再学绣。 |

## 四、外婆的固定收束对白

- 换装完成（外婆气泡）：衣裳不是穿得越满越好。站稳、走稳，知道自己为什么穿，才算准备好。
  - 气泡收起后通栏兜底（阿岚第一人称转述）：外婆看了看我身上的盛装，点了点头。**保留**该兜底，但受场景护栏约束（见下）。
- 问答收尾（B 方案：外婆收尾语作为**气泡第二页**，外婆口吻，留在她头顶；再点一次气泡直接消失）：
  - 首次：外婆气泡第一页＝回答，第二页「好咯，去做你的事。」
  - 后续：外婆气泡第二页「还有哪样想问的，随时问。」
  - 说明：收尾语只以外婆口吻留在气泡内，避免人称错位；此处**不设通栏兜底旁白**（`fallback: null`）；来源织带只属于回答页，翻到第二页自动隐藏。
- **场景护栏（bug 根治）**：气泡关闭是延时回调（约 170ms）。若玩家在气泡未收起时就切幕（如点门离家），回调可能在新场景里把兜底旁白覆盖到通栏，残留到第二幕。现记录气泡触发时的场景 `bubble._scene`，延时回调仅当 `bubble._scene === state.scene` 时才写通栏——同幕内正常显示兜底，跨幕则不再漏出。
