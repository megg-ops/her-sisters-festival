# 她的姊妹节

陪一位施洞苗族女孩，亲历她第一次自己准备的姊妹节一天。

多彩贵州·贵客松（Guikesong）赛道三·开放创新参赛作品。

## 一句话

通过 AI 文化对话，亲历苗族女孩的姊妹节一天——做姊妹饭、穿节日盛装、问外婆一件事、赴歌场赠饭。

## 怎么玩

- **在线体验**：`[部署完成后补 Vercel URL]`
- **本地直接玩**（无需安装任何东西，离线预设问答模式）：
  下载仓库后，双击打开 `她的姊妹节-demo.html`，浏览器直接运行。
- **本地跑真实 AI 问答链路**（可选）：
  ```
  set -a && . <你的凭证文件> && set +a
  node dev-server.mjs
  ```
  然后访问 `http://localhost:8788`。不配置 AI 网关凭证时自动降级为离线预设回答，不影响体验完整度。

## 技术栈

- **前端**：原生 HTML/CSS/JS 单文件（`她的姊妹节-demo.html`），无构建步骤、无框架依赖——场景切换、任务状态、三段式做饭小游戏、分层换装、气泡对话全部手写实现。
- **AI 代理**：Vercel Serverless Function（`api/ask.ts`，Node runtime）。密钥只存在于服务端环境变量，浏览器不接触；6 秒硬超时，超时或失败统一降级为本地预设回答，不阻断主线。
- **AI 模型**：`qwen3-max`（经 openai-next 网关，OpenAI 兼容协议）。
- **知识库**：`src/data/knowledge.json`，结构化 JSON，前后端同构读取（前端离线兜底 + 服务端问答上下文共用一份数据，不做向量检索）。
- **部署**：Vercel（静态文件 + Serverless Functions 同仓）。
- **协议感知降级**：页面检测自身是通过 `http(s)` 访问还是本地 `file://` 直接打开，后者自动跳过网络请求走离线预设——同一份代码同时支撑"公网部署走真实 AI"和"断网展位单文件保底可玩"两种场景。

## 内容与素材说明（重要）

本作涉及的服饰、银饰、姊妹饭制作、家屋陈设、节日场地等文化细节，均依据公开资料（贵州省博物馆、台江县人民政府官网、中国非物质文化遗产网等，具体来源见各资产同名 `.md` 文件与 `知识库.json` 的 `sources` 字段）创作，**当前均为原型资料，标注"待当地复核"状态**，正式发布前需邀请施洞当地文化工作者、传承人或研究者复核。

游戏内 AI 生成的"回声诗"明确标注为**当代创作，不是传统苗歌**；AI 文化问答只依据审核知识库回答，无相关资料时明确告知"这个我讲不准"，不编造苗语、传统苗歌或习俗细节。

本作不代表全部贵州苗族或全部苗族文化，聚焦当代台江施洞一地一节。
