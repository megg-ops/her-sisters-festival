## 一、核心理念

> **一切 UI 皆织物，一切色彩皆靛染，一切情绪皆记忆。**

整个游戏世界以「布」为母题呈现：画面嵌于深色织物画框之内，UI 组件是**缝在场景上的布片**，色彩以靛蓝染布的明度层次展开，情绪基调是温厚、静谧、带怀想的仪式感——像一个被仔细收存的针线包被慢慢打开。

**与 PRD 反参照的调和**：PRD 禁的是「古风卷轴形」「悬浮玻璃卡片」「金色描边」这些具体形态，不是质感本身。织物记忆的执行原则是 **「可用性为骨，织物为皮」**——所有布片组件都是实底、高对比、状态完整的现代控件，缝线与布纹只是质感层。PRD §11 的每一条（六态、44px、键盘焦点、非颜色状态）全部保留。

## 二、画面构成（舞台式三层结构）

| 层 | 内容 | 实现方式 |
|---|---|---|
| **画框层** | 全屏最外的深色织物边框（约 1.5–2.5vw 宽），带经纬织纹与磨损斑驳 | CSS：深靛底 + SVG 噪点 + 内阴影 |
| **场景层** | 绘本式插画场景（S0–S7），人物可见，晨光克制 | AI 生图（见 §六 提示词基线） |
| **织物 UI 层** | 布片组件「缝」在场景上：热点、任务、对话、字幕 | 纯 CSS 绘制（见 §四），不用生图 |

布面画框内可整体叠加 2–3% 麻布颗粒噪点（`mix-blend-mode: multiply`），让插画与 UI 共享同一块「布」。

## 三、色彩系统（Committed · 从参考图聚类提取）

### 3.1 设计令牌

| 令牌 | 色值 | 占比/用途 |
|---|---|---|
| `--ink-indigo` 墨靛 | `#131922` | 主背景基调、画框、暗部（参考图占比最高的主色） |
| `--deep-indigo` 深靛 | `#1A2438` / `#22304A` | 布面层次、UI 面板深底 |
| `--indigo` 靛蓝 | `#2A4A6B` | **交互主色**：热点激活、主按钮、链接 |
| `--lake` 湖靛 | `#2E6B8A` | 次级交互、亮布、图标 |
| `--wood-d` 深木褐 | `#403733` | 木构环境主色、中间调暗部 |
| `--wood-m` 暖木灰 | `#897E72` | 木环境中间调、麻布 |
| `--cloth` 米白布 | `#D8CCB4` | 布面亮部、浅色面板底、文字底 |
| `--light` 天光灰蓝 | `#C0CCCC` | 门洞/窗光冷亮层 |
| `--crimson` 绛红 | `#8F2D3F`（强调可提至 `#B53A5A`） | 点缀：任务高亮、情感强调，**小面积** |
| `--text-on-dark` | `#E8E0D0` | 深底上的正文（对 #131922 对比度 >12:1 ✓） |
| `--text-on-cloth` | `#1A1A18` | 米白布上的正文（对比度 >10:1 ✓） |

### 3.2 用色纪律

1. **深靛主导**：画面 60% 左右处于墨靛—深靛带；亮部只出现在光源（窗、门洞、火塘）和布片 UI 上
2. **绛红是绣线不是涂料**：只做小面积点缀（任务对勾、情感选择、关键强调），单屏不超过一处大面积
3. **暖褐做过渡**：木色系负责深靛与米白之间的中间调，避免画面发闷
4. **不做全幅米黄仿古底**（PRD §12.1）；米白只属于布片和光
5. **颜色不单独承载信息**：所有色彩语义伴随 ✓ 图形/纹样/文字（WCAG）

## 四、织物 UI 组件规范（纯 CSS 实现）

> 缝线、布纹、流苏全部用 CSS/SVG 绘制，**不由 AI 生图**——保证多组件像素级一致。

### 4.1 布片面板（Panel）

```css
.panel{
  background:#1A2438;                /* 深靛实底 */
  border:2px dashed #D8CCB4;         /* 米白缝线（虚线=手缝线迹） */
  border-radius:6px;                 /* 小圆角：布片是裁出来的，不是玻璃 */
  box-shadow:0 4px 14px rgba(4,6,11,.45);
  /* 可选：叠加 3% 布纹噪点 */
}
.panel--light{background:#D8CCB4;color:#1A1A18;border-color:#2A4A6B}
```

### 4.2 交互热点（Hotspot）

- 胶囊形：图标 + 文字名称（如「厨房 · 做姊妹饭」），布片质感
- **六态齐备**：默认（缝线米白）/ 悬停（靛蓝填充 + 轻上浮 2px）/ 键盘焦点（2px 实线 + 外发光描边）/ 按下（下沉 1px）/ 已完成（✓ 前缀 + 缝线变灰 + 名称后缀「已完成」）/ 不可用（降透明度 45% + 禁用图标）
- 最小 44×44px；焦点态不依赖颜色

### 4.3 对话框

- 底部固定布片面板（深靛底 / 米白缝线），说话人名牌为小织带标签（绛红底白字或米白底墨字），右下角可挂小流苏（CSS 三条短线）
- 正文 `#E8E0D0` 衬线，≤4 行；「点击继续」提示为小三角图形+文字
- **AI 回答**：名牌旁加「来源」小织带标签，可展开资料条目（PRD §8.4）

### 4.4 任务提示

- 轻量布面小票样式（米白底），置于角落不占画面中心
- 完成项用 ✓ 图形 + 删除线 + 「已完成」文字三重表达

### 4.5 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 叙事对白 / 标题 | Noto Serif SC（思源宋） | 布面上的手写感由衬线+字距承担，不引入手写体 |
| 英文/数字装饰 | Garamond 族 / EB Garamond | 参考图的书卷气质来源 |
| 系统辅助小字（设置、来源、字幕标签） | 无衬线（PingFang SC / Noto Sans SC） | 保证小字号可读性 |

### 4.6 织物细节库（CSS 素材）

- **缝线**：`border: dashed`（1.5–2px，米白或靛蓝）
- **十字缝点**：`radial-gradient` 重复背景或伪元素小十字（苗绣十字绣意象，用于面板四角）
- **靛染斑驳**：SVG feTurbulence 噪点叠加 + `mix-blend-mode: multiply`，透明度 ≤8%
- **冰裂纹**（蜡染意象）：用于「记忆卡」「文化手记」等记忆类组件的背景纹理
- **菱形纹带**（苗锦意象）：`repeating-linear-gradient` 45° 双色带，用于任务条、进度装饰边
- **流苏**：三条 2px 短线 + 末端小圆点，只用于对话框与记忆卡

### 4.7 动效

- 反馈动效 150–250ms（PRD §12.4）
- 入场动效 = **「缝上去」**：布片从 6px 偏移 + 1° 微旋 + 0 透明度进入，200ms ease-out——像最后一针落定
- 场景转换：遮挡 / 推镜 / 短交叉淡化
- `prefers-reduced-motion`：全部降级为 ≤100ms 短淡入或即时切换

## 五、场景插画规范（AI 生图方向）

- **画风**：绘本式插画，柔和中见笔触，**布面质感**（画面如画在粗麻布上，带经纬暗纹），边缘不做硬描边
- **光影**：单侧晨光/火光，克制；光是从窗、门、火塘来的，不做漫射糖水光
- **色彩**：深靛主导 + 暖木褐过渡 + 米白/天光亮部，绛红点缀——与 §3 令牌一致
- **材质细节**：靛染布的斑驳、木纹、陶器、竹器；盛装银饰以「绣感银白」呈现
- **人物**：第三人称可见，18 岁女孩便装/盛装两态；面容柔和不卡通化
- **当代痕迹**：手机、现代物件自然存在但小比例、不抢戏（PRD 设计原则 4）

### 提示词基线模板

```
[场景内容]。绘本式插画，画在粗麻布上的质感，布纹肌理，
深靛蓝（#1A2438 一带）主导的画面基调，暖木褐色过渡，
米白与天光灰蓝只出现在光源处，绛红仅小面积点缀，
柔和笔触，克制的单侧光照，边缘不描边，安静有生活气息，
当代生活痕迹自然存在，无文字，无水印
```

负面词基线：`文字，水印，金色描边，玻璃拟态，赛博，高饱和糖果色，动漫大眼，3D 渲染，照片写实`

## 六、生产纪律

1. **UI 一律 CSS 绘制**（§四），AI 只产场景插画与立绘——一致性靠代码不靠运气
2. 生图管线沿用已验证配置：OpenAI Next `/v1/images/generations` · `doubao-seedream-5-0-pro-260628` · 尺寸 1440x810（横）/ 1024x1024（物件特写）· 请求必须带非默认 User-Agent；响应 JSON 与图片即时落盘（URL 24h 失效）；**全部素材 8/29 24:00 前生成完毕**（账号 8/31 失效）
3. 每资产先 n=1 验证构图与风格漂移，通过再批量；同提示词不并发
4. 正式资产以真实施洞参考素材为据（PRD §19），纹样、银饰形制不做「通用民族风」臆造
5. 命名：`assets/{scene|char|prop}/名称-vN.png` + 同名 `.md` 记录参考来源与审核状态
